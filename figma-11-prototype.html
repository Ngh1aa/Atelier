11 / Prototype & interaction

The system moves
with a reason.

Live HTML prototype · working local commerce

The prototype is not a slideshow. Search, filtering, Saved, Bag, variant/size feedback, mini-Bag and local order state are real client-side behaviors; simulated external services remain explicitly simulated.

Flow 01Editorial → Product

Home → Collections → shoppable chapter → PDP. Expression guides entry; commerce takes over at evaluation.

Flow 02Search → Decide

Search / Filter / Sort → PDP → size/fit → Save or Add to Bag. Empty-state recovery is part of the flow.

Flow 03Size → Mini-Bag

Select a valid size → read truthful availability → Add to Bag → focus enters mini-Bag → Escape returns context.

Flow 04Validate → Confirm

Bag → Checkout → first invalid field receives focus → repair → browser-local confirmation record.
