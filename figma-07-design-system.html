07 / Design system

Quiet palette.
Strong ownership.

Foundations · tokens · interaction grammar

The system avoids “luxury by decoration.” Recognition comes from typography, rules, image behavior, spacing, indexed labels and transaction precision.

Colour

Neutral primitives, semantic states.

No decorative accent is needed for recognition. Error and success colours exist only to communicate state.

Typography

Serif interrupts. Sans executes.

Display serif owns editorial moments; sans-serif owns controls, navigation, price, state and transactional information.

Spacing

Shape

0px default radius

Hard edges and 1–2px rules keep the system fashion-editorial rather than SaaS-like.

Motion

110 / 180 / 280 / 560ms

Micro, state, disclosure and editorial durations. Reduced motion collapses them to immediate feedback.

Grid

Role-driven composition

Wide asymmetric editorial layouts become stacked, task-prioritized flows on tablet/mobile.

Primary action

Ink surface, white text, explicit hover/focus/pressed/disabled feedback.

Quiet action

Text or outlined control; never hidden behind hover-only discovery.

Media rule

Garment evidence must not be destructively cropped without a verified focal contract.

Accessibility intent

Visible focus, persistent labels, native controls where possible, live state regions and reduced-motion support.
