# Pink Parks product imagery

Product photography in this directory was sourced on 23 August 2026 from the public Pink Parks IAMXIAA New Arrivals collection:

https://pinkparks.com/collections/jlaunt-new-arrivals

The repository stores optimized local copies so ATELIER does not hotlink the storefront CDN. Each `-512.jpg` file is a responsive derivative of the corresponding 934 × 1556 source image. Product names, prices and commerce data remain ATELIER demo content; only the photography source changed.
